开源暨珠有线网络终端 1.3.19
===========================

启动：双击「开源暨珠有线网络终端.exe」。关闭窗口收到托盘，托盘「退出程序」才停止认证。

环境：Windows 10/11 x64，Npcap 1.89，.NET 10 桌面运行库。
启动器自动检测 Npcap；缺失时从 https://npcap.com/dist/npcap-1.89.exe 下载，校验安装包后打开安装窗口。
按向导完成安装即可，WinPcap 兼容模式已禁用。安装后重新检测；取消或要求重启时停止启动认证。
检测到其它 Npcap 版本时会提示，由你决定是否更换。
自动下载需要可用网络，离线电脑请提前手动安装 Npcap 和运行库。
缺少 .NET 时，启动器从 Microsoft 官方地址下载并安装。
首次配置驱动、运行库或后台任务时需要管理员授权。

便携版：完整解压后运行，设置写在本目录 state 下。
安装版：通过 Setup 安装，设置写在 %APPDATA%\CampusTerminal 下，可从 Windows 应用列表卸载。
安装版卸载保留账号设置和日志，需要时可在退出程序后手动删除 %APPDATA%\CampusTerminal。

程序可独立完成普通认证。使用官方客户端时，先断开本终端；官方客户端兜底默认关闭。
OCR 交还功能需要另行安装 Python 和 requirements-ocr.txt 中的依赖。

本版新增窗口缩放和设置页 IPv4 显示。日志保留最近 31 天的分段，重连历史保留 100 条。
后台日志位于 %APPDATA%\CampusTerminal\logs；便携版 GUI 日志位于本目录 state。
