# CampusTerminal 1.4.1

平台：Windows 10/11 x64。

本版加入新版检测和自动更新，修复重认证与界面稳定性问题。

## 更新

- 启动时检查 GitHub 新版本，主界面提供更新提示，可查看更新说明、立即更新或忽略该版本。
- 新增「发现新版本后自动更新并重启」，默认关闭。启用后自动下载并重启，遵循已保存的版本忽略选择。
- 更新包经过 SHA-256 校验，优先使用匹配当前版本的增量包，也支持完整更新包。按文件替换变化内容，保留设置、日志和安装类型；替换失败时回滚。
- 统一界面、后台及启动器的版本显示。
- 更新说明按标题和列表排版，弹窗按内容自适应宽高；超长内容可滚动阅读，小窗口下按钮自动调整排列。

## 修复

- 修复交换机周期重认证引发的反复断线，沿用现有会话和地址完成重认证，随后恢复心跳。
- 修复恢复记录处理时覆盖连接状态变量导致的界面崩溃。
- 修正恢复记录：将进行中的重连更新为成功，避免健康检查重复追加成功记录。
- 重认证成功后保持在线状态，减少界面在「在线」和「核验中」之间的跳变。
- 静默启动接入已连接后台时，主动刷新连接状态，避免重复发起自动连接。
- 修复更新弹窗的缩放问题，使其随主窗口调整大小。
- 修复更新脚本在部分 Windows PowerShell 环境下的文件校验兼容问题。

## 升级

升级前请先从托盘退出终端，再使用新版安装版或便携版。安装版按向导升级；便携版在原目录完整解压并覆盖程序文件，保留 `state/` 文件夹。

内置更新适用于 1.4.1 及之后的版本。更新时会短暂断开校园网认证，完成后重新打开终端。

环境要求保持为 Windows 10/11 x64、Npcap 1.89 和 .NET 10 桌面运行库。启动器按需引导安装依赖，自动下载需要可用网络。

- 后台检查 193 项、启动器检查 46 项通过；生产编译零警告、零错误。
- 原地重认证、恢复记录、在线阶段及静默接入的修复均已核对，并通过对应回归。
- 更新说明排版、自适应弹窗、更新包选择、文件保护、失败回滚和自动更新模拟流程通过。
- 便携包及更新包的文件哈希、版本标记、许可文件和隐私文件排除检查通过。
- 便携版与安装版的打包 GUI 预览，以及独立目录的安装、卸载验证通过。

本次验证覆盖离线回归、源码构建和发行包验证。校园网现场认证、长期在线及真实在线升级仍需实际环境验证。
